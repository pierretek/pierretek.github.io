About Me

Hi, I'm Pierre, a computer engineering student who loves firmware, embedded systems, and real hardware. I love programming systems that create real, tangible effects in the physical world, whether they move, light up, or respond to their environment.

I’ve been into electronics and robotics since I was a kid, and that curiosity grew into a passion for understanding how both hardware and software work. Over the years I’ve worked with languages like Java, C, Assembly, MATLAB, VHDL, Python, and others. Lately, I’ve been diving deeper into C++ and spending time with ESP32 development using the Arduino framework.

Outside of engineering, I enjoy chess, table tennis, biking, and taking long walks through unfamiliar places.

If you've read this far, thanks for taking the time to learn a bit about me. I hope you have a great day.

Projects

Simple VHDL Processor

➤

Architecture for an simple general purpose processsor written in VHDL

This architecture recieves two 8-bit values and performs specific functions depending on the provided opcode. The processor was waveform tested then implemented onto a real FPGA board

The input, output, and opcode signals were displayed on several seven-segment displays.

Repository

MPU6050 IMU Driver

➤

I built a lightweight Arduino driver for the MPU6050 IMU to read accelerometer, gyroscope, and angle readings over I2C.

The library includes calibration and configuration features to significantly improve measurement accuracy. I also wrote clear and detailed documentation to help others use the library in their projects.

Repository PlatformIO

ESP32 Power Supply Board

➤

I Designed a LiPo power management PCB that includes a charging circuit and a 3.3V buck-boost converter for safely powering an ESP32 Devkit V1.

The board charges a LiPo battery over USB‑C and plugs directly into the ESP32 using compatible pin headers. Both the schematic and PCB were created in KiCad, and an interactive BOM is available below.

Repository BOM

Line Following Robot

➤

An autonomous line following robot programmed in pure HCS12 Assembly

The hardware is a 4-wheeled programmable robot equipped with five light sensors to detect and follow a line. Front and back bumpers are used to detect dead ends and initiate a U-turn.

The robot can solve a short maze using a left‑turn algorithm at each intersection

Repository

ESP32-Hosted Webserver

➤

I Built an ESP32 based webserver, which can recieve commands to control an array of four LEDs.

The webserver hosts a console type interface where the user can control individual or multiple LEDs to turn on or blink for a specified amount of time

The web interface is made with HTML, CSS, and JavaScript while the ESP32 is programmed with C++

Try Demo Repository

ESP32 Api Dashboard

➤

Built a configurable ESP32 dashboard that lets users add, delete, and reorder up to five API endpoints on a TFT display.

The ESP32 hosts a webserver where users can set custom API links to be periodically polled and displayed, and each endpoint runs in its own FreeRTOS task to handle HTTP requests concurrently.

Repository Try Demo

Java Window Minigames

➤

Three simple minigames made in java using JFrames

You can choose between three different minigames and aim for a high score. Highscores are tied to player names and are persistently saved between sessions. The full score leaderboard can be viewed or deleted.
